# 学程 · 学期学习助理

原生微信小程序 + CloudBase，面向个人的课程、待办、复习计划与 AI 整理工具。

当前代码版本：**0.2.0 开发验证版（2026-11-06，北京时间）**。CloudBase `api` 函数已部署并通过启动自检；真实用户数据流、模型与 B 站联调、真机验收及正式小程序发布仍未完成。证据见 [版本说明](docs/releases/v0.2.0.md)。

## 使用

1. 微信开发者工具打开本仓库根目录，保留本项目 AppID 与原有云环境配置。部署到其他账号时才替换自己的公开配置。
2. 在「课程」录入学期、课程、重要度与掌握程度。在「今日」添加任务；截止日期可空，考试可填写复习范围。
3. 在「计划」录入可用时间与固定课程/占用时段，可每周重复。生成计划后，修改进度会自动重排；锁定冲突会明确提示，撤销不会复活已完成任务。
4. 「AI」中配置自己的兼容模型。文字与截图整理出的新增数据先确认再保存；截图要求模型支持图片输入。Key 云端加密保存，成功后移除本机明文；新备份不含 Key。
5. 首页同步状态表示真实同步结果。不同设备同时修改时停止覆盖，由用户选择本机或云端版本；恢复包含课程、任务、可用时段、排期和撤销信息。
6. 「复习资源」按当前任务检索 B 站实际视频，支持复制原链接。外部检索被拒绝时明确显示失败，不编造视频。

每天的未完成任务汇总在右上角「消息」。已取消无条件微信每日推送，不恢复邮件、短信或未经确认的通知方案。

## 开发

Node.js 版本范围见 package.json。运行 `npm test`、`npm run check-config`。

`cloudfunctions/api/core` 是排程纯函数的唯一来源；改动后运行 `npm run sync-shared` 生成小程序副本。测试会检查副本漂移。

当前界面以 `snapshots` 为唯一同步来源；旧记录类 API 保留兼容，不能把旧表中的记录当成最新快照恢复。云函数以微信 OPENID 隔离用户，数据库仅允许管理端/服务端访问。

配置与部署见 [配置清单](docs/SETUP-REQUIRED.md)，功能边界见 [功能说明](docs/FEATURES.md)。不提交密钥、环境文件、私有开发工具配置、缓存及用户数据。

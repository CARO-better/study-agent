# 未发布：极简玻璃界面

日期：2026-11-07（北京时间，改版始于 11-06）。基础版本仍为 0.2.0；本说明不代表小程序上传、体验版发布或正式上线。

## 范围

- 今日改为紧凑清单；删除口号、重复标题及常驻的编辑/资源/删除文字，次级动作放入更多菜单。
- 课程与设置采用分组列表；计划保留可用时间、固定安排和排期，减少说明及空态内容。
- 左上角常驻 AI 玻璃圆钮，展开当前页面上的助手浮层；底部保留今日、课程、计划、设置四入口。
- 全局浅色/深色/跟随系统、动效开关；浮动导航、工具按钮和弹层统一玻璃材质；不支持背景模糊时仍有可读底色。
- 原 AI 页面继续作为兼容入口；页面与浮层共享同一控制器，使用原模型、确认、排程与同步处理器。
- 按需下载 Lucide SVG，并保留许可证与固定来源提交；Apple、WeUI、Impeccable 参考下载在项目 output/ui-research 内，未改动用户级 skill、hooks 或 C 盘配置。
- 本地原创 Lottie 继续用于助手空态；高分屏 Canvas、静态降级、关闭动效、隐藏暂停、销毁及超时回退具备回归覆盖。

## 数据与升级

无需迁移学习数据。API、快照与学习字段保持原结构。显示偏好独立保存在 study_appearance_v1，不写入学习快照和含课程任务的备份。

在开发工具中重新编译项目即可试用。若新增组件遇到旧模板缓存，可关闭并重新打开项目窗口；不要清除用户数据。调试中曾观察到助手实例错误使用首页模板，重建项目窗口后恢复；此过程没有清除存储。

同步失败/冲突以紧凑提示和状态入口保留。点击同步图标可查看状态、同步或恢复；恢复和覆盖继续走原确认流程。云端当前连通性不能由 UI 编译结果推断。

## 独立审阅

审阅发现并修复了浮层带来的旧草稿覆盖风险：保存前比较最新记录及课程列表，记录被 AI 更新或删除时保留草稿并拒绝覆盖，避免撤销进度或复活已删除记录。新增回归还验证无关任务被新增时保留该任务、课程索引变化时不误关联。

关闭浮层会阻止尚未执行的后续工具；已经提交的云端排程请求仍可能完成，延续既有行为，不承诺撤销已发送请求。

# 学期学习助理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从零交付原生微信学习助理小程序及CloudBase后端，完成已批准设计中的课程、任务、计划、进度、模型、截图、B站和微信提醒链路。

**Architecture:** 原生小程序调用带微信身份校验的云函数。业务核心采用可注入时钟和外部服务适配器的独立模块，数据库是唯一正式状态来源；AI只生成可校验的建议。定时通知使用独立内部函数，并发安全的事件账本控制发送。

**Tech Stack:** 原生JavaScript/WXML/WXSS；Node.js；wx-server-sdk；腾讯云OCR SDK；Node内置测试框架；CloudBase文档数据库及云存储。外部模型和检索走HTTPS适配器。

**Spec:** 同目录《学期学习助理-产品与技术设计.md》，用户已于2026-11-04批准。

## Global Constraints

- 新项目根目录：`D:/study-agent/`，不采用D盘现有项目的源码。
- 提醒仅限北京时间08:00—23:00，每个任务每天最多提醒两次。
- 默认08:00和20:00摘要，用户可修改；完成/取消任务不继续提醒。
- 文字＋截图识别结果均需检查确认才创建正式数据。
- 自动重排未来计划、保留固定安排、支持撤回；撤回不改变真实完成状态。
- 用户自定义模型服务，Key加密保存在云端，客户端不可回读明文。
- 真实OCR、搜索、模型和微信联调与模拟测试分开报告。
- 不自动开通付费服务、购买套餐或提交上线审核；相关配置待实现就绪后具体说明。

## Review Focus

1. “周五”、跨年、学期周次缺失：不能静默猜定截止日期；由任务2覆盖。
2. 云函数管理员权限可能绕开数据库规则：每次访问必须校验当前owner；由任务2覆盖。
3. 锁定计划占满时段、撤回遇到后续手改：不能覆盖用户安排或造出空闲时间；由任务3覆盖。
4. 微信发送超时结果未知、跨北京时间零点和多调度实例：不盲重试、不突破每日上限；由任务6覆盖。
5. 自定义Base URL重定向、DNS返回私网、外部搜索内容含指令：不能泄漏Key或伪造资源；由任务4、5覆盖。

## 文件职责

- `miniprogram/`：app、页面、组件、共享服务；正式云端模式与明显标识的本地演示模式分开。
- `cloudfunctions/api/index.js`：用户业务路由、微信身份、输入输出边界。
- `cloudfunctions/api/core/`：领域校验、排程、版本、导入、模型和资源等可测试模块。
- `cloudfunctions/api/adapters/`：数据库、HTTPS、模型、OCR、B站检索。
- `cloudfunctions/reminder/index.js`：仅内部定时入口，通知决策和微信投递。
- `scripts/package-functions.js`：将通知依赖的公共业务模块复制进独立部署包；源模块只有一份。
- `tests/`：Node测试、适配器契约样例与联调入口。
- `deployment/`：集合、索引、规则、触发器和无密钥配置样例。
- `README.md`、`VERIFICATION.md`：导入部署步骤及真实验证结果。

推荐在当前会话由主代理按任务实现（Native），各任务共享领域接口，采用一次全量独立代码审阅，减少上下文切换并尽快形成可用版本。也可选择每任务独立实现与审阅的子代理模式。

用户确认计划及执行方式后开始产品代码开发；适用技能要求的Git隔离在执行前检查，若当前是非Git的独立生成目录则直接采用新项目目录，不操作其他项目仓库。

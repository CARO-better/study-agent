# 学程 · 学期学习助理

原生微信小程序，管理课程、学习任务和个人学习计划。

**当前版本：v0.1.0，本地试用雏形（2026-11-04）。**

当前小程序界面使用微信本地存储，未连接云端。仓库中的 CloudBase 后端基础代码不代表已部署服务。

## 立即试用

1. 在微信开发者工具选择「导入」，选择本仓库根目录（不是 miniprogram 子目录）。
2. 使用自己的小程序 AppID；project.config.json 中的 AppID 应替换为自己的注册账号。
3. 本地试用选择「不使用云服务」，编译后进入「今日」。无需填写模型密钥或云环境。
4. 在「课程」新增学期名称和课程；在「今日」新增任务；在「计划」添加未来可用时间后生成计划。
5. 可标记任务完成、锁定时间块或撤销上一次生成；关闭重开后仍可读取本设备数据。

设置中的示例数据需要主动确认后才添加。清除开发工具缓存、卸载或换设备可能丢失本地试用数据。

## 当前可用与待完善

可用：课程与任务增删改、任务完成切换、可用时段、本地排期、未排入原因、锁定和撤销。

待接通：云端同步、AI整理、截图识别、B站真实课程推荐和微信主动推送。当前界面会明确提示未接通，不会实际发通知。

本地试用版的撤销、进度和数据结构是简化实现，不等于已审阅云端排程的全部能力；目前未自动同步到云端，未来迁移需要显式映射。

## 开发验证

需要 Node.js，版本范围见 package.json。在项目根目录运行 `npm test`。

云函数依赖安装、CloudBase环境、数据库权限和部署说明见 cloudfunctions/api/README.md、deployment/INTEGRATIONS.md。不要把真实模型Key、AppSecret、环境文件和开发工具私有配置提交到仓库。

## 迁移与使用影响

- 云端快照使用 `snapshots` 集合。函数已部署；端到端使用前仍须核对 `docs/上云接入清单.md` 中的集合、索引、权限和环境变量，并以真实小程序身份验证读写。
- 模型 Key 保存在云端加密配置中；客户端本机缓存和新建备份不保留云端模式下的明文 Key。首次迁移可能要求重新填写 Key。
- 同步版本冲突会保留本地数据并要求用户选择处理方式；不要通过清空缓存来解决冲突。

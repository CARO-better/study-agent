## 两设备恢复与冲突

此项会替换整份快照，只在已备份且能明确区分版本时执行；两端必须是同一个微信用户。先等一端同步成功，另一端恢复后核对课程、任务、可用时间、固定课程及排期。不要通过清缓存制造空设备。

两端基于同一版本编辑验收任务，第一端先同步，第二端提交旧版本时应显示冲突并保留本机内容，不能静默覆盖第一端。明确选择保留哪份，再检查另一端恢复后数据一致。恢复等待期间如发生本机编辑，应拒绝覆盖并提示重新确认。网络过快无法制造该时序时记为未复现，不填写通过；该时序已有本地隔离回归。

只有固定课程、没有任务或课程记录的首次恢复场景已通过本地隔离回归；不要删除真实记录来重现，需另有隔离测试环境才能真机复核。

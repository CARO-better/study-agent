# 配置与部署要求

适用：0.2.0 开发验证版，2026-11-06。

## 当前项目

`miniprogram/config.js` 保存公开云环境 ID，`project.config.json` 保存公开 AppID。`npm run check-config` 现在检查这两处真实配置；显式传入 JSON 文件时仍可检查配置模板。

CloudBase 开发者登录与小程序用户身份不同。开发操作使用已授权的微信开发者工具 / CloudBase MCP；应用内以 `wx.cloud` 和服务端 `cloud.getWXContext().OPENID` 确认用户。

## 云函数

现有 `api` 为 Event 云函数，运行时 Nodejs20.19，不改变为 HTTP 服务，不新增公网网关。部署 `cloudfunctions/api` 并在云端安装 package.json 的依赖。调用模型需要足够运行时间，本次调整超时为 60 秒。

`STUDY_MASTER_KEY` 为已有 32 字节 base64 主密钥，只保留在云函数环境变量。不要更换、打印或提交；更换会使旧密文无法解密。更新函数配置时不得覆盖原有环境变量。

模型 Key 在小程序「AI → 设置」填写，云函数加密保存到 `providerSettings`。云端成功后本机仅保存地址、模型名、配置标志。网络失败不把新 Key 悄悄落盘，也不冒充保存成功。旧本地明文会在 AI 页成功迁移后移除。

云端代调模型不要求将每个模型域名加进小程序 request 白名单。选择图片模型前确认该服务/模型支持图片输入；纯文本模型不能因传入截图就自动具备识图能力。

## 数据库

按 deployment/database.json 建立 12 个集合，包含 snapshots，不包含未使用的 credentials。全部集合客户端直读直写关闭（ADMINONLY）；所有业务操作经过带用户归属检查的云函数。不要将公开只读权限用于私人任务、导入草稿或模型密文。

快照同步和云端排程均使用原有本地 ID，不重新导入到旧业务记录表。服务端 `sync.push` / `sync.plan` 要求 expectedRevision；旧客户端需要同步更新。

## B站检索

代码通过真实检索接口返回视频及来源。无 Cookie 时可能被风控拦截；如需配置，由用户在云端受保护环境变量中设置 `STUDY_BILI_COOKIE`，不要发送到聊天或写进仓库。失败时显示明确提示，不伪造推荐。

## 已取消或未申请的能力

本版使用站内摘要，不恢复无条件微信每日推送。没有购买套餐、创建新收费环境、申请新类目、配置支付或提交正式小程序上线审核。

真实模型效果、手机端恢复及小程序正式发布分别验收，不以 Node 单测、模板编译或云函数 Active 代替。

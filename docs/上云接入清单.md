# 上云接入清单（0.2.0）

更新时间：2026-11-06（北京时间）。旧版清单的“前端没有任何云调用”“credentials 必需”“默认配置检查只读示例”已不适用。

环境：cloud1-d2gobmqen9fd1cba1。项目使用已有 api Event 云函数，Nodejs20.19。不得创建替代环境迁走用户数据。

- 数据库 12 个集合已实查存在：profiles、semesters、courses、tasks、importDrafts、ownerLocks、providerSettings、providerUsage、uploadTickets、plans、planRevisions、snapshots。
- 权限已收紧并复核为 ADMINONLY；小程序只走云函数，不直接访问数据库。
- 主密钥已确认存在，未读取、输出或替换其值。
- 超时从 3 秒调整到 60 秒，环境变量与日志配置保留。
- 代码部署与实际调用证据见 [版本说明](releases/v0.2.0.md)。

当前界面以 snapshots 为唯一同步/恢复来源；旧业务表只作保留兼容。不要把旧表的任务数量误当成当前快照数量。云排程也使用同一快照，结果不要求迁入旧 plans 表。

升级前可导出无密钥的学习数据备份。升级后首次出现冲突时，由用户选择本机或云端版本。任何待同步状态都不代表已经备份到云端。
